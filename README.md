# THE WORLD TODAY — Thursday, 26 November 2026

One image that sums up the world's news of Thursday 26 November 2026, as a
newspaper front page: the Houthis' claimed strike on Saudi Arabia's Ras
Tanura refinery leads, with Ukraine's strike on the Savasleyka air base, the
US tariff proposals, Kim Jong Un's nuclear-weapons call, the first Pakistani
astronaut aboard China's Tiangong station, Bangladesh's garment-wage rise,
and a record-breaking cricket innings.

## How it works

`main.ts` copies the finished front page (`entry.png`, 1024×1024, rendered
locally with PIL) to `$MAKEFUN_OUTPUT_DIR/entry.png`. It reads no network and
draws nothing at runtime — the same bytes come out on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
